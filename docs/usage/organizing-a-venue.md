# Organizing Venues and Sessions

[Back to Posebook](../../README.md)

System administrators create physical venues, assign **Venue Coordinators**, and manage accounts. Venue coordinators edit their location, photos, and Instagram, create recurring sessions, manage every session there, and assign **Session Coordinators** using a registered user's email. Coordinator assignment does not expose a global user directory.

Use **Create Session** on a venue for a recurring program such as Mondays at 6:30 PM. Each session has separate weekdays, start time, time zone, pay, instructions, rules, invitations, roster, and calendar. Session coordinators edit only their assigned sessions and cannot edit the venue, manage siblings, or assign coordinator roles. Venue coordinators inherit those capabilities across all sessions at their venue.

Session settings include **Program Label** and **Participant Label**, defaulting to **Session** and **Model**. Use singular labels such as **Workshop** and **Instructor** to specialize the interface for another purpose. Calendars, rosters, invitations, and booking controls use those labels; **Pay** stays unchanged. Labels do not change booking rules: one person per date, one upcoming booking per person per program, organizer permission for repeat bookings, and the existing gender requirements still apply. Attendee registration is not implemented.

Session coordinators can invite models, review their session's roster and booking history, schedule or update bookings, confirm attendance, and manage dated schedule exceptions when a drawing is added, moved, or closed.

Invitations provide private, single-use registration links. A model must accept an invitation to join a session. Joining grants an initial booking; coordinators can invite models to book again after they complete a drawing. A paused model can keep an existing booking and cancel it, but cannot book or reschedule until resumed. Memberships and invitations are independent across sessions.

Email is used for account recovery and optional invitation delivery. Posebook does not yet send automated drawing reminders or booking notifications.
